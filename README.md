# Primer sajta — stomatološka ordinacija

Одностраничный пример сайта для стоматологической клиники: услуги, команда, галерея
кабинета и форма записи. Демонстрационный макет, не сайт действующей клиники.

## Что внутри

- `index.html` — вся страница в одном файле, без внешних CDN.
- `assets/img/` — изображения кабинета, оборудования и карточки услуг.
- Разметка адаптивная: от 320 px до широкого десктопа, без горизонтальной прокрутки.
- Форма записи — интерфейсный макет: отправка не подключена к серверу.

## Чего здесь нет

- Названия, адреса и телефона реальной клиники; имена сотрудников заменены специализациями.
- Аналитики, трекеров и внешних шрифтов.

## Как смотреть

Открыть `index.html` в браузере или поднять статику: `python3 -m http.server`.
